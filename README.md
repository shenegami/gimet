# Omni-Supervisor

منصة تشغيل ذكية لإدارة المشاريع والملفات والتقارير تعتمد على Next.js 14 وSupabase وتكاملات OpenAI. يوفر التطبيق لوحة قيادة حديثة بالعربية مع مشرف افتراضي يحلل المخاطر وينتج التقارير ويوصي بخطوات التحسين.

## المتطلبات
- Node.js 18+
- حساب Supabase مهيأ مع الجداول الواردة في `supabase-schema.sql`
- مفتاح OpenAI صالح (اختياري لتشغيل التكامل الحقيقي)

## البدء السريع
```bash
npm install
npm run dev
```

قم بتعبئة ملف `.env` بناءً على `.env.example` قبل تشغيل المشروع.

## الميزات الرئيسية
- 🔐 مصادقة عبر Supabase Auth (جاهزة للتهيئة)
- 🧭 لوحة معلومات لعرض المقاييس والتنبيهات والتقارير
- 🗂️ إدارة مشاريع مع واجهة كانبان ونماذج إضافة سريعة
- 🧠 مشرف ذكي يحلل البيانات ويجيب عن الأسئلة عبر واجهات `/api/ai/*`
- 📊 توليد تقارير أسبوعية بتنسيق Markdown
- ☁️ إدارة الملفات مع واجهة رفع وتصفح مبنية على Supabase Storage
- 🔔 مركز تنبيهات للتذكير بالتأخيرات والمخاطر
- ⚙️ أدوار مستخدمين (مشرف، مدير، متابع)

## البنية الهيكلية
```
src/
  app/
    api/ai/*      # واجهات الذكاء الاصطناعي
    files/        # إدارة الملفات
    notifications/# التنبيهات
    projects/     # لوحة المشاريع
    reports/      # التقارير الأسبوعية
  components/     # مكونات واجهة معاد استخدامها
  lib/            # وظائف مساعدة وبيانات تجريبية
```

## البيانات التجريبية
يوجد ملف `src/lib/demo-data.ts` يحوي بيانات وهمية لعرض إمكانات التطبيق دون اتصال بقاعدة بيانات حقيقية. استبدل المصدر بوظائف Supabase عند الانتقال للإنتاج.

## الاختبارات
التطبيق يستخدم `next lint` للتحقق من جودة الشيفرة:
```bash
npm run lint
```
